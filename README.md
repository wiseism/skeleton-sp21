# README

Berkeley-CS61B
### 课程概述
CS61B（Data Structures） 是加州大学伯克利分校（UC Berkeley）EECS 系的核心基础课，2021年春季学期由 Josh Hug 主讲，核心聚焦数据结构、算法分析与软件工程实践，以 Java 为教学语言，强调代码效率、内存优化与大型程序设计能力。
- 课程官网：https://sp21.datastructur.es/
- 先修要求：CS61A/CS88/E7 或同等编程基础（无需Java经验）
- 学分：4学分；周期：14周（2021年1–5月）

### 核心目标
1. 掌握常用数据结构（链表、树、哈希表、图等）的原理、实现与性能对比。
2. 学会算法复杂度分析（时间/空间），理解不同数据结构的适用场景。
3. 建立软件工程思维：模块化设计、测试调试、代码规范与团队协作。
4. 熟练使用 Java 及工具链（IntelliJ、Git、JUnit），具备独立开发中型项目的能力。

### 课程内容（三大阶段）
#### 阶段1：Java 与面向对象（第1–5周）
- Java 基础：语法、类与对象、引用传递、静态变量/方法。
- 面向对象：封装、继承、多态、接口、抽象类、异常处理。
- 基础数据结构：数组、链表（SLList/AList）、递归与分治。
- 工具与实践：IntelliJ 配置、Git 版本控制、JUnit 单元测试。

#### 阶段2：数据结构与算法（第6–10周）
- 树与图：二叉搜索树（BST）、平衡树（AVL/红黑树）、图的遍历（BFS/DFS）、最短路径（Dijkstra）。
- 哈希与集合：哈希表（HashMap）、冲突解决、并查集（Disjoint Set）。
- 排序与优先队列：堆排序、快速排序、归并排序、优先队列（Heap）。
- 算法分析：渐近复杂度（Big-O）、时间/空间权衡、性能测试与优化。

#### 阶段3：软件工程与大型设计（第11–14周）
- 高级主题：迭代器、泛型、设计模式、内存管理与垃圾回收。
- 大规模系统设计：模块化、接口设计、代码复用、性能调优。
- 综合项目实战：从零设计并实现复杂系统（如游戏引擎、数据处理框架）。

### 考核方式（总分12800分，无curve）
#### 1. 项目（Projects，35%）
- Project 0（2048，640分）：Java入门，实现2048小游戏，熟悉基本语法与面向对象设计。
- Project 1（Deques，640分）：实现双端队列（链表/数组版），掌握测试驱动开发（TDD）与代码审查。
- Project 2（数据结构综合，1600分）：设计并实现哈希表、平衡树等，重点考察效率与稳定性。
- Project 3（BYOW，1600分）：团队协作（2人），从零设计大型系统，涵盖需求分析、架构设计、编码实现与测试。

#### 2. 考试（Exams，50%）
- 期中1（1280分）：第5周，覆盖Java基础、面向对象与简单数据结构。
- 期中2（1920分）：第10周，覆盖树、图、哈希、排序与算法分析。
- 期末（3200分）：第14周，全面考察课程内容，侧重综合应用与系统设计。
- 政策：允许携带手写笔记；期末可“覆盖”期中低分（Clobbering Policy）。

#### 3. 作业与实验（12.5%）
- Homework（3次，960分）：理论题，辅助考试复习。
- Labs（10次，640分）：每周编程练习，巩固课堂知识，包含代码审查与性能测试。

#### 4. 每周调查（2.5%）
- 14次课程反馈，取最高10次计分（320分）。

- 讲座（Lectures）：预录视频发布于官网，每周MWF 13:00–14:00 Zoom直播答疑。

- 平台：Ed（论坛）、GitHub（代码管理）、Gradescope（自动评分）、Beacon（成绩追踪）。

### 课程特点与学习建议
#### 特点
- 重实践：项目驱动，代码量要求高，注重动手能力与工程规范。
- 强度大：每周需投入15–20小时，项目周期长，需合理规划时间。
- 质量高：伯克利经典课程，内容体系完善，为后续算法、系统设计课程打下坚实基础。

#### 学习建议
1. 提前预习Java：利用首周快速掌握基础语法，跟上课程节奏。
2. 重视项目实践：独立完成代码，理解数据结构底层实现，而非仅调用API。
3. 积极参与讨论：利用论坛与实验课答疑，避免闭门造车。
4. 定期复盘总结：梳理知识点关联，归纳算法模板与设计模式。

## 🎮 proj3 - BYOW (Build Your Own World) 详解

这个项目完全对应 README.md 第 28-32 行的内容，是一个**从零设计并实现的复杂系统（游戏引擎）**。

### 📂 proj3 目录结构

| 模块 | 说明 |
|------|------|
| **TileEngine** | 瓦片引擎 - 负责游戏世界的渲染 |
| **Core** | 核心引擎 - 主游戏逻辑（Engine.java、Main.java） |
| **InputDemo** | 输入系统 - 支持键盘、随机、字符串等多种输入方式 |
| **Networking** | 网络模块 - BYOWClient 和 BYOWServer（可选的多人模式） |
| **lab12** | 实验 12 - 世界生成演示（BoringWorldDemo、RandomWorldDemo、HexWorld） |
| **lab13** | 实验 13 - MemoryGame（内存游戏） |

### 🎯 这个项目涵盖了阶段3的所有主题：

| README 第28-32行提到的主题 | 在 proj3 中的体现 |
|-------------------------|------------------|
| **迭代器、泛型** | 数据结构的使用（如随机世界生成） |
| **设计模式** | TileEngine 的设计、InputSource 接口等 |
| **内存管理与垃圾回收** | 大型游戏世界的内存优化 |
| **模块化** | 清晰的模块划分（TileEngine/Core/InputDemo/Networking） |
| **接口设计** | InputSource 接口、Tileset 等 |
| **代码复用** | 可复用的瓦片引擎、随机数工具等 |
| **性能调优** | 游戏世界的渲染性能优化 |
